# Custom Skills Pack

Optional curated Hermes Agent skills for Android/Termux installs.

Counts:

- Marketing skills: 34
- Design/UI/UX skills: 21
- Android helper skills: 1
- Total custom skills: 56

Install from the repository root:

```sh
bash scripts/install-custom-skills.sh --all
bash scripts/install-custom-skills.sh --marketing
bash scripts/install-custom-skills.sh --design
bash scripts/install-custom-skills.sh --android
bash scripts/install-custom-skills.sh --library
```

The DESIGN.md reference library is stored separately in `custom-skills-library/`.
