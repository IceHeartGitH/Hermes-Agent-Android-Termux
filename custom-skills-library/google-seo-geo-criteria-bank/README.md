# Google SEO & GEO Criteria Bank

Public-safe criteria library for Hermes Agent site-inspection skills.

Contents:

- 201 Google SEO criteria.
- 186 Google GEO / AI Search criteria.
- 387 professional inspection-ready criteria total.

Each criterion is a Markdown note with definition, credibility, requirements, audit evidence, pass/fail conditions, fix recommendation, priority, risk, and sources.

Use with these bundled skills:

- `google-seo-site-inspector`
- `google-geo-site-inspector`
- `google-seo-geo-site-inspector`

This library does not promise 100% indexing, ranking, or AI citation. It is designed to evaluate maximal conditions for crawl, indexability, ranking eligibility, search appearance, and GEO citability.
