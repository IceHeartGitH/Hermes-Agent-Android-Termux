# Custom Skills Library

Reference libraries used by the custom Hermes skills.

Included now:

- `awesome-design-md/` — 74 brand/style `DESIGN.md` references from https://github.com/VoltAgent/awesome-design-md

Recommended install target on a device:

```text
~/.hermes-venv/skill-libraries/awesome-design-md/
```

The `awesome-design-md-library` skill can use this local library together with the `design-md` skill.
